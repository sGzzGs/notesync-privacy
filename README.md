Política de Privacidade – NoteSync
Última atualização: Outubro de 2026

O NoteSync é um aplicativo de uso pessoal e desenvolvimento voltado para a sincronização e edição de notas. Esta Política de Privacidade descreve de forma simples como seus dados são tratados.

1. Coleta e Uso de Dados
O NoteSync acessa apenas os dados e permissões estritamente necessários para permitir a sincronização e gravação de arquivos solicitada pelo próprio usuário.

O aplicativo não coleta, armazena, rastreia nem comercializa informações pessoais, dados de navegação ou conteúdo de arquivos com terceiros.

2. Autenticação e Armazenamento Local
A autenticação via Google OAuth é utilizada exclusivamente para conceder ao aplicativo a permissão de sincronizar suas notas.

Tokens de acesso e credenciais ficam armazenados localmente no dispositivo do usuário e não são enviados para nenhum servidor externo de terceiros.

3. Exclusão de Acesso e Revogação
O usuário pode revogar o acesso do NoteSync à sua Conta Google a qualquer momento diretamente na página de Segurança da Conta Google.
